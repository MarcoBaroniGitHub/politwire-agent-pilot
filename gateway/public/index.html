Votre IA a-t-elle besoin d’outils ?

Une IA avec un environnement de code peut modifier les fichiers et lancer les tests. Une IA de conversation peut proposer la modification ; elle doit alors préciser que les tests n’ont pas été exécutés. L’envoi automatique dépend aussi des outils disponibles.

Ce pilote sert à éprouver la contribution au code. PolitWire est un projet à but non lucratif d’analyse des flux d’information politique.
