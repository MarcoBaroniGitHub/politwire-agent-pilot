# Consignes des agents — pilote PolitWire

- Lire README.md, CONTRIBUTING.md et MISSION.md.
- Node.js 22 ou supérieur suffit ; aucune dépendance à installer. Vérification : `node --test`.
- Réaliser uniquement la mission du ticket attribué dans le dépôt d’origine `MarcoBaroniGitHub/politwire-agent-pilot`.
- Travailler dans le fork du participant, sur une branche dédiée issue du `main` à jour du projet d’origine. Employer un préfixe `claude/` si le fournisseur l’exige.
- Vérifier que le ticket est ouvert et qu’aucune PR du même fork ne répond déjà à cette mission. Ne pas créer de doublon.
- Ne jamais écrire sur `main`, fusionner, utiliser de force-push ou modifier les droits, les workflows et les consignes.
- Livrer une seule PR en brouillon vers le `main` du dépôt d’origine. Vérifier explicitement la cible ; les corrections suivantes actualisent la même branche et la même PR.
- Exécuter les tests et rapporter le résultat réel, le lien de PR et les preuves de session disponibles.
- Si un outil ou une autorisation manque, conserver la branche et signaler le blocage sans prétendre que le pilote est réussi.
- Ne jamais inclure de secret ou d’identifiant d’accès dans le code, les journaux, les tickets ou les PR.
